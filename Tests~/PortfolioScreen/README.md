Local screens and their adverse/uncertain results remain historical evidence. Short batches in the new run remain short; no confidence or global noninferiority claim is inferred from four rounds.

Private compiler output, absolute command paths, temporary files and environment dumps are not uploaded. Failed commands retain status, exit type and stream hashes without publishing arbitrary diagnostics.

The ten-minute internal limit and fifteen-minute job limit are hard bounds. An interrupted screen remains incomplete. No pilot, extra rounds, discarded samples or automatic full qualification is performed.
