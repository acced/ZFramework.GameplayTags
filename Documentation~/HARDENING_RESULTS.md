# 整数版加固：执行结果、收益和成本

本轮采用用户上传的整数优化版，而不是 name-based rc.1。版本为 **2.1.0-rc.1**。目标是修复无效输入、序列化、计数、事件和池生命周期问题，并保留整数存储的主要性能优势；**不是所有公开操作全面提速，也不是无缺陷或真实 Unity 验收声明**。

第一次资格验证 [38718497157](https://github.com/acced/ZFramework.GameplayTags/actions/runs/38718497157)保留：既有测试通过，新测试错误地对 null 对象直接调用实例方法而失败。后续将其修正为实际支持的静态扩展入口；没有把 null 实例调用改成合法行为或忽略候选测试失败。

28 格（8 和 1024 个显式成员，14 个操作）、每格四对独立进程，顺序 AB/BA/BA/AB，共 **224 条正式记录，全部验证通过**。另有 **303 条仅上传版的校准记录**。两侧同格采用共同计数，最大 16,777,216 次；只读短操作触及上限后仍可能不足 100 ms。**60 条正式短批次全部保留**，没有 A/A、筛除离群值、控制减法或事后择优重跑。

## 未解决范围与发布边界

没有真实 Unity Editor/Player、Inspector/Prefab/场景、Mono、IL2CPP 或移动设备执行。没有 rc.1 的同机对比，不沿用历史倍数。主分支按用户授权升级整数路线，但包保持候选版本；不自动创建稳定 Release/tag。

父容器的贡献所有权、自定义父链异常、极端长父容器链递归以及 OOM 事务性仍有边界，详见 HARDENING.md。裸池引用归还后不得继续使用。注册表仍是域内一次冻结；旧 name-based main/rc.1 的 Settings、Redirects、序列化容器字段和排序契约不是此次兼容范围。
