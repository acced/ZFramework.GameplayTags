## 2. 通用游标为什么不采用

游标按ulong跳过零字，再从pending发出非空16-ID记录，保持顺序。Low仅用于非零pending，尾部无效位由集合不变量保证为零。复制迭代器和反复耗尽都测试。禁止遍历同时修改。

两平台实际managed value size：Records16→24B，公共Enumerator32→40B；集合字段不变。0B不意味着值拷贝、栈空间和额外分支免费。

ARM64，262144/8分散的Dense完整枚举30.649→7.414微秒；但10000/4096连续Dense枚举13.440→14.715微秒，持续回退且A/A通过。

ARM64完整枚举子组，cursor的Micro枚举28/60项持续退化，Dense枚举4/60项持续退化。组合版对应也是28/60和4/60。

组合版完整bench持续退化：x64 75/2280，ARM64 57/2280。因此当前cursor和combined不作为统一替代。拆分Dense专用游标是后续候选，不是已经通过本轮测试的实现。
